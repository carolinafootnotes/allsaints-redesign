# Platform — why Squarespace

**For the vestry — May 2026**

> We're not picking a website. We're picking what the office and staff will live with for the next 5+ years. The platform decision is bigger than the design.

## Recommendation

**Squarespace, Business plan, billed annually with the nonprofit discount.**

**~$248 the first year, ~$276/year after that.** All-in. No plugin licenses, no theme renewals, no developer retainer.

## Why we're moving off WordPress

Our current site is on WordPress with the ColorMag Pro theme. WordPress is powerful and free *as software* — but expensive in time and risk.

| WordPress reality (today) | Squarespace reality (proposed) |
|---|---|
| 10+ plugins, each with its own update cycle and security patches | One vendor, one login, one billing line |
| Theme is paid and dated; updates can break the site | Templates are included and auto-maintained |
| Adding a sign-up requires plugin choice, configuration, sometimes code | Add a section, paste a SignUpGenius link, done |
| One person learns it; if they leave, no one can update it | Anyone on staff can learn it in an afternoon |
| Hidden cost: hours per month chasing plugin conflicts and updates | Hidden cost: none. Squarespace handles all of it. |

**The vestry's question shouldn't be "do we need to migrate?" — it should be "what is WordPress costing us today in time and risk?"** The answer is more than $276/year.

## Squarespace plan comparison

| Plan | Annual cost | What we'd give up by going lower |
|---|---|---|
| **Personal** | $192 ($16/mo) | No custom code blocks (we'll need these for embeds), no advanced analytics, no professional email |
| **Business** ← *recommended* | $276 ($23/mo) — **$248 first year with nonprofit discount** | — |
| Commerce Basic | $432 ($36/mo) | Built for online stores; we don't sell anything |
| Commerce Advanced | $780 ($65/mo) | Same as above, plus features we don't need |

**Business is the right tier** because we need:
- **Custom code injection** for the OnRealm Give widget, Facebook livestream embed, and Google Maps with our exact pin
- **Advanced analytics** so we know what pages get used (we currently have *none* — the WordPress analytics plugin was never configured)
- **Professional email** ($0 extra for the first year via Google Workspace integration) — useful for any new staff email addresses
- **No transaction fees** on any future ecommerce (e.g., if we ever sell event tickets)

## Nonprofit discount

Squarespace offers two paths:

1. **`NONPROFIT` code at checkout** — 10% off the first annual payment. ~$28 saved.
2. **TechSoup partnership** — verified 501(c)(3)s get an ongoing ~10% discount. Worth applying if All Saints isn't already in TechSoup.

Either way, the math is small but real. We'll claim whatever stacks.

## Who builds it

Three honest paths. The vestry decides which one we take.

| Path | Time / cost | Trade-off |
|---|---|---|
| **Nate builds it** ← *recommended* | $0 cash, ~8–15 hours of his time over 4–6 weeks | He'll know the tool; can train others |
| Hire a Squarespace Circle freelancer | $1,500–3,500 one-time, 1–2 weeks | Faster, but adds a third party to a process we want simple |
| Parish volunteer with Squarespace experience | $0 cash, 4–6 hours volunteer time | Depends on whether such a volunteer exists |

In any of these paths, all the **content, copy, code snippets, images, and step-by-step build instructions are pre-produced** before Squarespace work begins. The build itself is execution, not design.
