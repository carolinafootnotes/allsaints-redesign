# Brand colors — Squarespace palette + hex reference

Site Styles → **＞ next to Colors → Edit palette** → click a swatch's **value field**, type
the hex. Black + white are built in (text). Squarespace auto-generates the section themes
(Lightest / Light / Bright / Dark / Darkest) from these.

## Palette to enter (into the Edit palette swatches)
| Hex | Role |
|---|---|
| `#7b2332` | Burgundy — primary brand (dark sections, accents) |
| `#c8a977` | Gold — accent (buttons, highlights) |
| `#faf6ee` | Cream — light section backgrounds |
| `#1a1a1a` | Ink — darkest sections, body text |
| `#5e1a28` | Deep burgundy — darkest theme |

## Per-section Colors theme (rough mapping)
- Cream / light content sections (Welcome, Visit, most) → a **Light** theme
- Burgundy sections (Worship, Connect strip) → a **Dark** theme
- Near-black sections (This Week, hero overlay) → **Darkest**
- Gold-forward accents → a **Bright** theme

Squarespace *generates* themes from the palette, so you don't control exactly which color
lands where — set the palette, then per section pick the closest theme and eyeball it.
